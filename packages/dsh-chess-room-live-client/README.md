# DSH Chess Room Client 1.2.1

原生 DSH 棋室页面：鲸娘动画、玩家头像、短气泡、棋盘、棋谱和可取消的工作区/对话选择。

先安装同仓库 `@local/dsh-chess-room` Host。正式 Client 导出为 `client-context-121.js`；保留的 `client.js` 是 1.2.0 演出基线。当前构建请运行仓库根目录 `pnpm build`。

自有代码采用 MIT。JavaScript 内嵌的鲸娘图片和独立素材采用 ASSET-LICENSE.md 中的分发说明。旧来源记录的本地使用限制已由维护者 2026-11-06 的明确公开分发确认更新。
