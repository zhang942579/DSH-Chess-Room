# DSH Chess Room Host 1.2.0

五子棋规则、独立 DSH 模型候选、合法性确认、持久化、账号头像和上下文绑定。正式入口 `entry-v6.js`，当前页面由同仓库 Client 1.2.1 提供。

先使用 DSH Plugin Manager 安装本 bundle，再安装 `@local/dsh-chess-room-live-client`。源码安装前请在仓库根目录执行 `pnpm install --frozen-lockfile` 和 `pnpm build`；推荐使用 `pnpm package` 的两个安装目录。

完整说明见仓库根 README。自有代码采用 MIT，素材授权独立，vendor 验证器保留 Apache-2.0。
